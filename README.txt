# 가천대 길잡이 Google Maps 버전

## 사용 방법
1. `index.html` 파일 맨 아래에서 `YOUR_GOOGLE_MAPS_API_KEY`를 본인의 Google Maps API 키로 교체합니다.
2. Google Cloud Console에서 다음 API를 활성화합니다.
   - Maps JavaScript API
   - Directions API
3. GitHub Pages에 `index.html`을 업로드합니다.
4. API 키 제한을 사용하는 경우 HTTP referrer에 아래처럼 등록합니다.
   - `https://seunghyun27.github.io/*`

## 기능
- 건물 선택
- Google Maps 도보 경로 자동 표시
- 예상 거리/시간 표시
- 출발/도착 마커 표시
